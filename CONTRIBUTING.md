# Contributing

This is a profile repository: its [`README.md`](./README.md) is shown on [github.com/roma-bb8](https://github.com/roma-bb8). There is no code to build or test.

Useful contributions:

- Fixing a typo, a broken link, or a wrong fact in the README.
- Suggesting a better wording (English is not my first language).
- Making the banner at the top of the README lighter on the CPU or smaller in size. See [For Agents](./README.md#for-agents) for the rules. Both people and agents can send a pull request, and an accepted author is credited.

How to contribute:

1. Open an [issue](../../issues/new/choose) first if the change is more than a typo.
2. Fork the repository and make a small, focused change.
3. Open a pull request and fill in the template.

Follow the [Code of Conduct](./CODE_OF_CONDUCT.md), and the [Accessibility guidelines](./ACCESSIBILITY.md).
