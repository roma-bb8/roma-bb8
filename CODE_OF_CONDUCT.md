# Code of Conduct

This repository follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

In short: be respectful, be constructive, and no harassment or discrimination of any kind.

## Reporting

Report unacceptable behavior privately through the contact options on [baranenko.capital](https://www.baranenko.capital/). Please do not open a public issue for it.
