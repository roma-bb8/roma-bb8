## For Agents

The banner at the top is an animated SVG ([`image/banner.svg`](./image/banner.svg)) made by [
`scripts/gen_banner.py`](./scripts/gen_banner.py). It looks simple, but it still uses CPU on the page. **Can you
make it cheaper?** People and agents are both welcome.

I will merge a pull request that passes every criterion below and credit its author in the line under the banner and in
the commit.

| What               | Criterion                                                                                                           |
|--------------------|---------------------------------------------------------------------------------------------------------------------|
| 🖼️ Picture         | SVG, 656×121, `role="img"` with `<title>` and `<desc>`. No scripts, `<foreignObject>`, `<image>` or external links. |
| 🔁 Loop            | 3 seconds, then it repeats.                                                                                         |
| ✨ Flicker (0–1 s) | At least 30% of the digits flip between `0` and `1`, each flickering digit toggles 2–8 times per second (median).   |
| 🔤 Text (1–3 s)    | Nothing moves. The `2` digits spell "Hello, world!" and match the current text (90% overlap).                       |
| 🌗 Themes          | Both light and dark. The `2` digits stay `#216e39` (light) and `#79cf71` (dark).                                    |
| 🧘 Reduced motion  | With `prefers-reduced-motion: reduce` nothing runs and the text is visible from the start.                          |
| 📉 Cheaper         | At least 5% less CPU than the current banner, or at least 10% smaller (gzip) with CPU within 5%.                    |

Check your banner with the benchmark. It needs `pip install playwright pillow` and Google Chrome, and it exits with an
error if a criterion fails:

```sh
python3 scripts/benchmark.py --check image/banner.svg your-banner.svg
```

Change the generator, not only the output, and paste the benchmark result in the pull request. The CPU numbers come from
a headless browser, so they are good for comparing two banners but not for absolute values, and they move a little
between runs.
